# CodeAlpha_Task
📊 Data Visualization with Python

This project is part of the Code Alpha internship tasks. It demonstrates how data visualization techniques can be used to explore and analyze a dataset using Python libraries like *Pandas*, *Matplotlib*, and *Seaborn*.

📁 Dataset

- *Source*: [Netflix Titles Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows)  
- *Format*: CSV
- *Attributes*: Title, Director, Cast, Release Year, Country, Type (Movie/TV Show), and more

📌 Objective

- Load and inspect the dataset
- Visualize trends in show releases over the years
- Plot graphs for better understanding of the data
- Make the visualizations clear and well-labeled

🛠️ Tools & Libraries Used

- Python 🐍
- Pandas 📋
- Matplotlib 📈
- Seaborn 🎨
- Google Colab

📊 Sample Visualization

- *Barplot* of number of shows released each year
- Customized figure size, color palettes, axis labels, and titles

✅ Conclusion

The project successfully visualizes the trends in Netflix show releases. It helps understand the peak years and type distribution visually.
